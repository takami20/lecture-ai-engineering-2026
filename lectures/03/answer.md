## 宿題

- 取り組んだレベル：基礎 

- やったこと：
* エージェントがツールを選ぶとき、何を手がかりにしているかを確かめるため、次の2つの実験をした。質問はどちらも同じ「LoRAとQLoRAの違いは？」。
1. **`tools.py` の `search_glossary` の docstring を書き換えて比較**
   - 元：`query には調べたい用語を1つだけ入れる（例: "LoRA"）。`
   - 変更後：`query には、調べたい用語を複数まとめて入れて検索してよい（例：「LoRA QLoRA」）。`
2. **`agent.py` の INSTRUCTIONS から、用語集（search_glossary）を使う指示を削除**
   - docstring は元のまま、システムプロンプト側だけ変えて、ツールが使われるかを確認しました。

- 結果：
**docstring 元の設定**
```
[tool call]   search_glossary({'query': 'LoRA'})
[tool call]   search_glossary({'query': 'QLoRA'})
[usage] input_tokens=1344, output_tokens=178, requests=2, tool_calls=2, cost=0.0008482
```

**docstring 変更後**
```
[tool call]   search_glossary({'query': 'LoRA QLoRA'})
[usage] input_tokens=1049, output_tokens=240, requests=2, tool_calls=1, cost=0.0009147
```

**INSTRUCTIONS から用語集の指示を削除（docstring は元のまま）**
```
[tool call]   search_glossary({'query': 'LoRA'})
[tool call]   search_glossary({'query': 'QLoRA'})
[usage] input_tokens=1296, output_tokens=189, requests=2, tool_calls=2, cost=0.0008613
```

| 条件 | tool_calls | 入力トークン | 出力トークン | コスト |
|---|---|---|---|---|
| docstring 元の設定 | 2 | 1344 | 178 | 0.0008482 |
| docstring 変更後（複数まとめて可） | 1 | 1049 | 240 | 0.0009147 |
| INSTRUCTIONS から用語集の指示を削除 | 2 | 1296 | 189 | 0.0008613 |

* どの条件でも、回答の中身（LoRAは重みを固定して低ランク行列だけ学習、QLoRAはベースを4ビット量子化してLoRA）と「関係する回：第2回」は正しく出力された。

- 気づき・疑問：
**気づき**
* **docstring の一文で、ツールの呼び方がそのまま変わった。**「1つだけ」と書くと用語ごとに2回呼び、「まとめてよい」と書くと1回にまとめて呼んだ。モデルは docstring を、ツールの使い方の説明書として読んでいた。
* **ツール呼び出しが減ると入力トークンが減った（1344→1049、約22%減）。** 1回目のツール結果を2回目の判断のために送り直す分がなくなったためだと思う。
* **ただしコストは逆に上がった（0.0008482→0.0009147）。** 出力トークンが178→240に増え、出力のほうが単価が高いからだと考えられる。変更後は「LoRA（Low-Rank Adaptation）」のような補足や箇条書きが増えて回答が長くなっていた。トークン数とコストは必ずしも一緒には動かない。
* **INSTRUCTIONS から用語集の指示を消しても、ツールは使われた。** 質問の内容と docstring の「この講座に固有の言葉について答える前に使うこと」だけで、モデルは使うべきツールを判断できた。ツールを使うかどうかは、システムプロンプトより docstring（ツールの説明）に左右されると感じた。入力トークンは1344→1296と、削除した1行の分だけ減った。
**疑問**
* まとめて検索した場合、trace の tool return が途中で切れていて、QLoRA の結果まで返っていたかを確認できなかった。回答にQLoRAの正しい説明はあるが、それが用語集から来たのか、モデルがもともと知っていた知識なのかを見分けるにはどうすればいいか。
* 逆に、docstring 側から「答える前に使うこと」を消したら、ツールは使われなくなるのか。どちらの指示がどれくらい効いているのかを切り分けて試したい。
* 出力トークンが増えたのは docstring 変更の影響なのか、生成のたびに出るばらつきなのか。悩んでしまった。
